# Flutter Map Memo

地図上にピンとメモを残し、現在地から移動経路（トラックログ）を記録・管理できる Flutter アプリです。
外部フォルダを使う運用と、フォルダを選ばずアプリ内へ保存する運用の両方に対応しています。

## 主な機能

- URL タイル地図の表示・切替
- 地図中心へのピン追加、タイトル・メモ・色の編集、削除
- 現在地の表示と地図の追従
- GPS 位置情報を使ったトラックログの記録
- トラックログ一覧での複数選択・削除
- 選択したトラックだけを地図に表示
- 設定した表示期間に応じたトラックログの絞り込み
- フォルダを切り替えたときに、トラックの選択・表示条件を安全にリセット
- Android の Storage Access Framework（SAF）による外部フォルダへの読み書き
- 外部フォルダ未選択時のアプリ内ストレージへの自動保存

## 動作イメージ

1. 地図を表示し、任意の位置にピンとメモを追加する。
2. 記録開始ボタンから現在地の移動を記録する。
3. 記録一覧で必要なログを選択し、削除または地図への表示を行う。
4. フォルダを選択した場合はその配下へ、未選択の場合はアプリ内へデータを保存する。

## 保存先

ピンとトラックログは、保存ルートの配下に次の構成で保存します。

```text
{保存ルート}/
└── save_data/
    └── map_data/
        ├── pin.json
        └── track_log/
            └── track_YYYYMMDD_HHmmss.json
```

保存ルートは次のように決まります。

| 状態 | 保存ルート |
| --- | --- |
| 外部フォルダを選択済み | 選択したフォルダ |
| 外部フォルダ未選択 | アプリの Documents ディレクトリ |

Android では、Download など Scoped Storage の制約を受ける場所でも SAF を使ってフォルダへのアクセス権を保持します。アプリ内保存時は通常のファイル API を使うため、初回設定なしでピン・トラックログを利用できます。

## トラックログの表示ルール

地図に表示するトラックログは、次の2つのモードで切り替わります。

| モード | 地図に表示するログ |
| --- | --- |
| 設定の表示期間 | 設定した日数内に開始したすべてのログ |
| 選択して表示 | 一覧で選択し「地図に表示」を実行したログだけ |

「設定の表示期間に戻す」を実行した場合、一覧の選択状態も解除します。また、保存フォルダを切り替えた場合も、別フォルダのログを誤って表示・操作しないように選択状態と表示条件を初期化します。

## 設計

機能ごとに `data` / `domain` / `presentation` を分け、UI・状態管理・永続化処理の責務を分離しています。

```text
lib/
├── core/       # ルーティング、テーマ、共通ユーティリティ、SAFサービス
├── folder/     # 保存フォルダの選択・復元
├── location/   # 現在地の取得と位置情報エンティティ
├── map/        # 地図表示、地図上の操作、トラック記録の制御
├── pin/        # ピンの作成・編集・削除・JSON永続化
├── setting/    # アプリ設定と設定ファイルの永続化
└── track/      # トラックログの保存・一覧・表示条件
```

- 状態管理: Riverpod
- 画面遷移: go_router
- 地図表示: flutter_map
- 位置情報: geolocator
- データ形式: JSON
- Android 外部ストレージ: MethodChannel + Storage Access Framework

### 保存処理の考え方

フォルダ選択の結果は `FolderSelection` として状態管理し、ピン・トラックの各機能はその保存ルートだけを受け取って読み書きします。これにより、外部フォルダ・SAF URI・アプリ内ストレージの違いを、各機能のUIに持ち込まない構成にしています。

外部フォルダの選択ダイアログをキャンセルしたときは、すでに選択済みのフォルダを維持します。意図しないアプリ内保存への切替を防ぐためです。

## 開発環境

- Flutter SDK: `^3.10.8`
- Dart SDK: Flutter に同梱のもの
- 主な動作対象: Android / iOS

## セットアップ

```bash
git clone <repository-url>
cd flutter_map_memo
flutter pub get
flutter run
```

実機でトラックログを記録する場合は、位置情報の利用を許可してください。Android で外部フォルダを使う場合は、設定画面から保存先を選択します。
